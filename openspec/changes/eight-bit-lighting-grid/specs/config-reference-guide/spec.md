## ADDED Requirements

### Requirement: Document 8-Bit Lighting Grid and New Lighting Keys
The hardware reference guide at `GUIDE/HARDWARE_CONFIG.md` SHALL document the 8-bit lighting grid and new configuration keys `lights.beacon` and `lights.work_light`.

#### Scenario: Looking up beacon and work light configuration
- **WHEN** a user checks the reference guide for `lights.beacon` or `lights.work_light`
- **THEN** they find hardware assignment tokens, brightness defaults, and the 8-bit mapping table
